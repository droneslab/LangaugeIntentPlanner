# Corridors, Not Detours

Research project website for **Corridors, Not Detours: Bounding Language Preferences by Local Opportunity and Embodiment**, by Pranay Meshram and Karthik Dantu, University at Buffalo.

This standalone static page adapts the CLEAR project-page template. The repository name `LangaugeIntentPlanner` preserves the requested spelling. It contains website assets, not the research implementation. The poster and extended abstract are not distributed on the website.

## Preview

Run `python3 -m http.server 8000` from this folder and open http://localhost:8000.

## GitHub Pages

Publish the repository root from the `gh-pages` branch using GitHub Settings → Pages. All asset and document links are relative and work under a project URL.

## Content provenance

- Poster: `LanguageIntentPlannerV2/Paper/Corridors_Not_Detours_48in.pdf`.
- Extended abstract: `LanguageIntentPlannerV2/Paper/BridgingNavigation2026/main.pdf` and its section sources.
- Figures: the abstract's `framework_v2_preview.png`, `corridor_local_opportunity_worked_example.png`, `terrain_intent_dual_robot_corridor_compliant_v2.pdf`, and `agent_intent_dual_robot_corridor_compliant_v2.pdf`.
- Author names and affiliation follow the poster.
- Headline confidence intervals and case counts follow the poster; method interpretation and validation boundaries follow the abstract. The evidence concerns typed intents in held-out simulation. Free-form language grounding and physical validation remain future work.
